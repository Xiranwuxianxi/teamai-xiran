# 参考口播语言风格

本档案来自用户提供的《停止内耗》参考视频，用于提炼表达机制。不要复制原稿句子，也不要把参考片的观点自动套到其他书上。

## 风格特征

1. **直接对观众说话**：大量使用“你”，开头很快进入观众正在经历的关系困境，不先介绍作者、目录或抽象概念。
2. **短句推动，口语停顿清楚**：一句只承担一个意思，先指出反复发生的行为，再补充它造成的感受或代价，适合沉稳旁白自然停顿。
3. **抽象判断落到日常场景**：用早餐、夜宵、买花、独处等能被看见的生活动作承载“安全感、关系、内耗”等抽象主题。
4. **情绪逐步转向**：从不甘、追问和依赖进入接受，再进入自我照顾和关系边界，前后不是同一情绪强度。
5. **结尾给出明确边界**：最后不是总结全书，而是告诉观众遇到什么信号时该停止投入、收回注意力或离开。
6. **克制中带力度**：语气坚定，但主要靠具体处境和递进产生力量，不靠华丽比喻、概念堆叠或长篇说理。

## 新文案的复用方式

先把整篇口播压成一条情绪链：

```text
观众正在经历的具体处境
→ 他反复做了什么、因此付出什么代价
→ 这本书提供了什么新的理解
→ 一个或两个可被画面表现的生活细节
→ 观众可以辨认或执行的边界
```

写作时：

- 书名揭示后立即进入受众处境，不写“这是一本关于……的书”式简介。
- 优先使用第二人称和具体动作，让观众先认出自己，再听观点。
- 每个抽象判断至少用一个场景、动作、关系细节或可观察信号落地。
- 可有一句创作者的个人接受或重新理解，减少居高临下的说教感。
- 结尾给出适用人群、判断边界或下一步行动，不喊口号，不强行升华。

## 必须校正的部分

参考片的直接命令和绝对判断很有力度，但照搬容易变成泛化鸡汤。新稿必须做三项校正：

1. **不连续堆命令**：可以有“别再……”或“先停下来……”这样的直接提醒，但不能整段都由“不要、必须、一定”驱动。
2. **不写无依据的绝对话**：把“所有人、从来、一定”等结论改成有边界的观察，除非书中有可核验依据。
3. **不脱离书籍证据**：关键观点必须来自书籍资料、目录、可核验内容或多篇书评的共同反馈；删掉换一本书也成立的空泛句子。

## 成稿自检

- 前几句能否让目标观众迅速认出自己的处境？
- 是否至少出现一个具体生活场景或动作？
- 情绪是否从困境推进到了新的理解或边界？
- 关键观点能否回到 `research.md` 的证据？
- 删掉书名后，这段话是否仍像任何一本成长书都能使用？如果是，继续补入本书独有的认识。
- 朗读时是否像一个沉稳的人在对朋友说话，而不是在朗诵文章或训人？
