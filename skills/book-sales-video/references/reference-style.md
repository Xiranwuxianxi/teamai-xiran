# 参考视频结构档案

本档案来自用户提供的参考视频，只保存可复用的结构证据。不要把它当作必须逐帧复制的模板。

## 使用边界

- 本页所有秒数、帧数和图片数量都是对参考片的测量，不是新视频的默认值或验收线。
- 新视频总时长由通过审阅的口播稿、OpenChatCut 中的实际配音和必要的片头/轮播衔接共同决定。
- 正文配图数量由语义、动作、场景和情绪变化决定；每张图时长跟随对应配音段，不按参考片平均值分配。
- 可复用的是“短情绪开场 → 节奏轮播 → 书名揭示 → 主题正文”这条形式链路，不继承参考片的具体内容和数值。

## 媒体事实

- 时长：53.404 秒。
- 画面：1080×1440，3:4。
- 编码：H.264；容器平均帧率约 24.88fps，时间基准显示 30fps。
- 音频：AAC，44.1kHz，双声道。
- 当前项目交付仍服从项目 `AGENTS.md`：9:16、1080×1920、30fps。参考片的 3:4 只用于构图理解。

## 时间结构

| 近似区间 | 内容 | 可复用规则 |
|---|---|---|
| 0.07–1.40s | 一段暗色情绪视频，字幕“今天分享的是 / Today's share” | 观察：短视频先建立主题情绪，不提前讲正文 |
| 1.40–2.23s | 六张旧书主题图高速轮播 | 观察：硬切跟随音效节拍，具体张数和间隔不继承 |
| 约 2.23s | 当前书《停止内耗》主视觉出现 | 最终卡点同时承担书名揭示与正文入口 |
| 2.23–53.40s | 正文旁白与主题配图 | 观察：约 9–10 组视觉母题；新视频按实际文案重新分镜 |

硬切检测到的主要轮播边界约为：1.40、1.53、1.70、1.83、1.93、2.07、2.23 秒。轮播包含《自渡》《人间失格》《去有风的旷野》《窄门》《活着》《日出之前》等过往主题卡，随后进入当前书。具体书名不是模板资产；用户应提供有权使用的新轮播图。

## 音频节奏

- 0–约 1.2 秒为“今天分享的是”的口播区。
- 约 1.4–2.2 秒出现密集、近等间隔的节奏音效，配合快速轮播。
- 约 2.23 秒人声重新进入并报当前书名。
- 轮播张数应由实际音效峰值决定；参考片的六张只是一条观察记录，不作为默认经验。

## 正文视觉语言

- 全片高对比、暗背景，黑白灰为主，橙色只做少量情绪或视觉焦点。
- 人物经常背对镜头、独处或处在具有空旷感的空间，画面与“关系离开、内耗、自我价值”主题一致。
- 画面不是每句都换：一个视觉母题覆盖相邻的 1–3 句话，在人物、场景或情绪发生变化时再切换。
- 正文主视觉大致经历：手持书封面、问号/困惑、站立人物、背影与画框、桌边人物与玫瑰、孤身站台、躺椅阅读、桌前独处、漂浮衣物等 9–10 组母题。
- 画面带轻微运动或元素变化，转场克制。初稿不需要先复刻复杂合成，可用高质量静帧配合轻微推近或平移。

## 版式观察

- 书名和作者长期位于画面顶部，白色、居中。
- 中文主字幕位于画面中下部；参考片另有较小英文副字幕。
- 底部有很小的来源/账号信息。
- 新视频默认做中英文双语字幕：中文为主、英文为辅。底部账号信息和更精细版式在初稿审阅后确认。

## 不能直接继承的内容

- 不直接复用参考片中的书封、书名、人物图、字幕或水印。
- 不复制参考片的原旁白或完整视觉合成。
- 不把参考片 53.4 秒、六张轮播图或 9–10 张正文图写成固定常数；它们只提供起始估计。
