# 剪辑节奏与特效规范

所有帧位从最终旁白可听毫秒与 OpenChatCut 当前 timeline fps 派生。默认画布 1080×1920、30fps；两者冲突时先停下修正。

## 轨道

| 轨道 | 内容 |
|---|---|
| V1 | Pexels 开场、轮播、揭示背景、正文图 |
| V2 | 主书真实封面：一条普通、可见、可编辑的 image 片段 |
| V3 | 标题、作者与唯一中英双语字幕层 |
| A1 | 单条完整旁白 |
| A2 | 从第 0 帧开始的 BGM |
| A3 | `library:sound:mechanical-clicking-loop` |
| A4 | `library:sound:cash-register-success` |

## 开场、轮播与揭示

- 开场中心显示“今天分享的是 / Today, I'd like to share”，不在底部重复字幕。
- A3 只放一段连续机械音效；读取真实峰值后，一峰硬切一张不同封面。轮播内部没有转场。
- 最后一张轮播到揭示使用约 0.10 秒光溶，优先当前库中可用的 organic dissolve；没有则使用短 cross dissolve。
- 揭示时 V1 为 AI 背景，V2 为微信读书真实书封。该书封必须是普通 `image` 片段，位于背景正上方；不能用全画布 Motion Graphic 承载图片。A4 只放一次，书封入场重音与音效锚点对齐。
- 书封入场约 0.23 秒：`opacity 0 → 1`、`scale 0.42 → 0.60 → 最终值`，并从略低的位置落到最终居中位置；按当前 fps 换算，不能写死帧数。最终画面以约 52%–60% 宽、水平居中、书名下方、左右留白为准。入场后保持静止，不添加持续呼吸、横移或旋转。
- 书封弹出的同一时刻，V3 在上方显示 `《书名》` 和 `作者 / 著`。这组文字从揭示持续到视频末帧，正文阶段不得随字幕卡切换、消失或改变位置；揭示段底部不再重复同样的书名作者字幕。

## 正文动效与转场

- 每张正文图恰好一个呼吸/慢推近效果。默认无位移、单次且比常规慢约 10%：`x=0`、`y=0` 固定；`scale 1.02 → 1.085`（片段 55% 处）`→ 1.035`（片段末尾）。不得重复第二次呼吸或在尾部快速缩回。优先使用已实测的 `builtin:zoom`、`shape=slow-push`，或用 scale 关键帧做等价轻微呼吸；禁止静态图片直接拼接。
- 揭示到正文第一张以及正文相邻图之间使用约 0.20 秒 `builtin:tr-cross-dissolve`。
- 放大后必须检查主体、左右满幅、上下粗纸和字幕框没有被裁坏或露黑边。

## 配音与声音

- 同一语义内停顿 0.12–0.25 秒；普通句间 0.25–0.45 秒；段落/视觉转折 0.45–0.70 秒。
- 唯一例外是有完整 A3 覆盖的无旁白轮播，可为 0.80–1.20 秒并记录原因。
- 删静音后按更新的 `voice-timeline.json` 同步重排全部轨道，不能依赖单轨 ripple。
- BGM 从第 0 帧开始，默认无人声；先以低于旁白的音量试听，必要时 duck。A3/A4 必须可辨认但不得盖住报书名。

## 字幕

- 中文在上、英文在下，均白字、清晰黑描边、单行。
- 1080×1920 起始值：中文 76px/800，英文 42px/600；中文每卡最多 11 个有效字符。
- 统一使用正文图预留的同一纸面字幕框，不遮挡主体，不留下重复字幕层。

## 验收

读回并核对每个效果和音效实例；抽查开场、轮播中点、揭示的入场/中段/稳定三关键帧、每个正文边界和末帧。确认 V2 中书封是可见的普通图片项，而非不可直观编辑的 Motion Graphic；在实际渲染中检查居中、左右留白、书名不被遮挡。试听第一二句、最长停顿、每个段落边界和结尾。缺少任一音效、转场、正文动效、BGM 或字幕样式时，状态为 `blocked-not-deliverable`。

所有操作通过本机 OpenChatCut MCP 完成。端口变化时重新运行桥接发现；不得调用旧 ChatCut 云端接口或编辑器付费代理。
