# 正文配图视觉系统

正文风格锁定为用户确认的“粗纸油画画外留白 v3”。默认预设位于 `../assets/visual-style/rough-paper-oil-vignette.json`；主视觉锚点是 `../assets/visual-style/approved-rough-paper-oil-v3.png`，每次生图都必须使用。`../assets/visual-style/reference-warm-paper.png` 只是最初来源参考，不得单独决定最终视觉。

## 风格锁定

- `styleId` 固定为 `rough-paper-oil-vignette-v3`，`styleLocked` 为 `true`。
- 每次图像生成都把主视觉锚点作为第一风格参考，要求保持纸张、油画媒介、笔触粗细、基础配色，并采用“场景至少 70%、左右满幅、仅上下留白”的版式。
- 允许随文案变化：场景、物件、人物动作、景别、视角、场景块位置、边缘形状，以及一个低饱和主题强调色。
- 不允许自行变化：摄影/插画媒介、粗纸类型、油画笔触机制、基础暖色世界、画外留白定义和“场景至少 70%、左右满幅、仅上下留白”的默认比例与方向。
- 用户没有明确说“换风格”或“解锁风格”时，不生成风格候选、不改写预设、不用其他生成结果替换主锚点。

## 风格定义

先把整个 9:16 画幅理解为一张粗糙暖米白纸，再只在其中一部分画油画场景。没有被画到的纸面形成留白：

- 20%–30% 的画幅保持为未上色的原始纸面，只能位于顶部、底部或上下两端；纸面只看得到明显纸纤维、纸浆颗粒、轻微色差和自然磨毛。
- 油画场景至少占 70% 画幅，默认目标为 70%–80%，横向必须延伸到左右边缘；以干刷、断笔、薄擦、刮擦或未闭合轮廓在上下方向自然结束。场景应成为画面主体，不能像贴在大空纸上的小插图。
- 留白是场景之外的纸，不是被画出来的墙、天空、地面、雾气、桌布或浅色背景。
- 场景采用写意但可读的叙事油画：人物和物件比例自然，形体由概括色块、可见鬃毛笔触、薄涂与局部厚涂建立；避免照片级皮肤与镜头锐度。
- 粗纸齿纹必须从薄涂和干刷区域透出来；颜料厚处保留轻微堆色和刮刀痕，不能只在完整照片上覆盖统一噪点。
- 色彩以暖米白纸、旧亚麻、黄褐、橄榄绿、深瓶绿和陶土色为底；每本书可加入一个低饱和主题色。

## 版式规则

- 9:16 竖屏。油画场景为横向满幅的开放式 vignette：左右边缘触达画幅，只有上下方向可以留出原始纸面；不做完整矩形照片框。
- 场景块边缘使用 `dry-brush-fade`、`broken-edge`、`scumbled-edge` 或 `open-contour`；不使用完整矩形照片边框，也不做撕纸拼贴边。
- 每张在 `shot-plan.json` 中写明 `paperBlankRatio`、`paperBlankPlacement`、`paintedScenePlacement` 和 `paintedEdgeTreatment`。
- `paperBlankRatio` 通常为 `0.20`–`0.30`，默认优先使用 `0.20`–`0.25`；`paperBlankPlacement` 只能是 `top`、`bottom` 或 `top-and-bottom`。场景每张均横向满幅，可通过上下留白的比例、人物位置、景别、视角和边缘形态形成变化，不能左右缩窄或固定成角落小块。
- 景别和视角描述的是“油画场景块内部”的镜头；画外纸面不属于场景空间，也不参与景别判断。
- 双语字幕优先放在未上色纸面；纸面不足时可使用场景内预先规划的低信息区，但不能覆盖人物、书封、手部动作或高对比笔触。
- 当前书封由微信读书真实封面单独叠加；正文油画中只出现无字书本或局部书页，不生成可识别书名。

## 镜头与题材适配

镜头规划仍优先于风格。相邻图片必须改变场景块内部的景别和视角，同时保持相同粗纸、油画笔触、颜料质感与色彩世界。

- 心理、关系和成长：门口、桌面、窗边、通勤、收纳、离开或重新行动等具体生活动作；避免连续孤独背影。
- 文学：地域空间、时代物件、天气、空镜和动作细节；避免把复杂作品做成一句鸡汤的象征海报。
- 商业、认知和方法：工作台、笔记、会议前后、路线选择、整理和决策动作；用局部油画场景和画外粗纸降低普通商务图库感。
- 历史、传记和社会：先保证时代与身份可核验；不确定时采用物件、建筑局部或概念场面，不冒充真实史实。

人物连续出现时保持年龄、发型、服装和气质一致。画面可以没有人物，但必须承担一个明确的叙事功能。

## 生图提示词组成

每张提示词从 `visual-style.json` 和对应的 `shot-plan.json` 合成：

```text
整张 9:16 粗糙暖米白纸 + 20%–30% 未上色画外纸面，仅在上方、下方或上下两端
+ 至少 70% 横向满幅油画叙事场景 + 主体身份与具体动作 + 场景和时间 + 叙事功能
+ 场景内部的景别、视角与主体位置 + 场景在上下方向的边缘位置，左右触达画幅
+ 干刷、断笔、薄擦、刮擦、可见鬃毛笔触 + 粗纸齿纹穿透薄颜料
+ 场景块边缘自然消失，不是矩形照片，不是撕纸拼贴
+ 基底色和本书主题强调色 + 双语字幕使用未上色纸面
+ 无文字、无书名、无 logo、无水印
```

每次提示词明确写：主锚点用于锁定粗纸、油画笔触、配色、画面边缘和留白比例，只更换当前分镜的内容、景别、视角和场景块位置，不复制锚点中的车站内容。来源参考仅用于理解灵感，不复制食物、餐具、桌面构图，也不要生成摄影画面。

## 禁用倾向

- 普通数码照片加泛黄、油画滤镜、降饱和或胶片颗粒冒充粗纸油画。
- 用空墙、天空、地面、雾气或浅色场景背景冒充画外纸面。
- 纯白无纹理底、光滑塑料 3D、玻璃拟态、紫蓝渐变和 AI 光晕。
- 油画场景纵向铺满画幅而不给字幕保留纸面，或把未上色纸面填满装饰、阴影和高对比笔触。
- 在左、右边缘或角落留出未上色纸面，或把场景缩成未触及左右边缘的小块。
- 厚重棕黄色复古、污渍、破损纸边和强烈做旧；风格应温暖、干净、可读。
- 硬矩形图片框、撕纸拼贴、剪贴人物、多层纸片和海报文字。
- 每张重复同一场景块位置、同一景别、同一视角或同一干刷边缘形状。
- 让图像模型重画书封、书名、作者、字幕、logo 或账号水印。

## 逐张与整组检查

1. 是否只有约 20%–30% 画面为未上色的真实纸面，且纸面只在上方、下方或上下两端？油画场景是否至少占 70%，并横向触及左右边缘？
2. 是否看得到粗纸纤维和纸齿，以及真正的干刷、断笔、薄擦和局部堆色？
3. 油画场景是否仅在上下方向以自然笔触结束、左右满幅而不放进矩形框？
4. 场景是否仍自然可读，主体是否在做一个与文案对应的具体动作？
5. 与前后图是否属于同一粗纸油画世界，同时景别、视角、主体位置、上下留白比例和边缘形态有变化？
6. 中文与英文字幕是否能完整放在未上色纸面，画面内是否无文字、书名、logo 和水印？
7. 与主视觉锚点并排时，是否仍像同一套纸、同一套颜料和同一位画者完成？

只有用户明确要求“换风格”或“解锁风格”时，才更新锁定状态并重新确认；不要自动恢复旧候选风格，也不要每条视频重复风格海选。
