# Creative Toolbox

Reusable materials for writing UGC ad scripts. Load this on-demand during Phase 2 when picking hooks / phrases / proof types / CTA closing lines.

For per-product-category narrative guidance, see the main SKILL.md — Phase 2 — Category Quick-Reference (kept inline because it's the primary decision table).

---

## Hook Types + High-Converting Keywords

| Type       | Example                                         | Best for             |
| ---------- | ----------------------------------------------- | -------------------- |
| Negation   | "Stop wasting fridge space!"                    | Replacement products |
| Identity   | "If you're obsessed with..."                    | Community/hobby      |
| Pain point | "Stop worrying about..."                        | Functional products  |
| Comparison | "Which wins?"                                   | Upgrade products     |
| Test       | "Do NOT buy unless it passes..."                | Quality products     |
| Question   | "Going on vacation but worried about your cat?" | Pets/family          |

High-converting words: Game changer / You need this / The GOAT / Total lifesaver / Under $X / Satisfying

---

## Persuasive Phrases (use directly in VO)

- "Trust me on this." / "You have to try this."
- "Total game changer for [audience]." / "Literal game changer."
- "It makes your [X] feel brand new."
- "Best [X] upgrade I've ever made." / "I finally found the [X]."
- "Stop overpaying for [X]."

---

## Proof Types (pick one)

Visual proof (before/after) / Social proof (reviews/ratings) / Authority proof (professional endorsement) / Process proof (show the mechanism)

---

## CTA Closing Lines

| Type         | Example                                | Best for             |
| ------------ | -------------------------------------- | -------------------- |
| Limited deal | "Grab this deal before it's gone."     | Active promotion     |
| Price anchor | "Under ten dollars."                   | High value-for-money |
| Social proof | "Thousands of 5-star reviews."         | Well-reviewed        |
| Functional   | "Never run out of power again."        | Functional           |
| Emotional    | "Movie nights will never be the same." | Premium/emotional    |

> "Link in bio" can go at the end, but isn't required. Emotional/functional closings can stand on their own.
