# 晚间/涨价/专题模块 Prompt 模板库

## 模块 A：晚间业绩公告

### 查询入口（使用 neodata-financial-search）

```bash
# 单次自然语言查询
python3 scripts/query.py --query "{日期} A股半年报业绩预增净利润公告，近1-3天发布的"
```

### 可选查询组合

| 编号 | 查询语句 | 用途 |
|------|---------|------|
| A1 | `{日期} A股半年报 业绩预增 净利润公告，近1-3天发布的` | H1 业绩预增 |
| A2 | `{日期} A股半年度 扭亏为盈 净利润公告，近1-3天发布的` | 扭亏为盈 |
| A3 | `{日期} A股三季报 业绩预增 净利润公告，近1-3天发布的` | Q3 季报期 |
| A4 | `{日期} A股年度 业绩预增公告，近1-3天发布的` | 年报期 |
| A5 | `{日期} A股业绩快报 净利润公告，近1-3天发布的` | 业绩快报 |

### 结果输出格式

```markdown
### A. 晚间业绩公告（YYYY-MM-DD 盘后）

| 公司 | 代码 | 业绩预告核心 | YoY增幅 | 映射方向 | 可信度 |
|------|------|-----------|---------|---------|--------|
```

## 模块 C：每日临时专题（按需触发）

### 触发方式

用户直接说明当日专题需求：
- "今天梳理一下两存扩产受益链"
- "帮我抓取华为昇腾链的核心标的"
- "今天专题：HBM产业链"

若用户未提及，跳过本模块。

### 查询策略（以两存扩产为例，使用 neodata-financial-search）

| 编号 | 查询语句 | 目的 |
|------|---------|------|
| C1 | `{日期} 长江存储 扩产 设备 招标，过去30-60天` | 长江存储扩产动态 |
| C2 | `{日期} 长鑫存储 扩产 设备 DRAM，过去30-60天` | 长鑫存储扩产动态 |
| C3 | `{日期} 半导体设备 国产 长江存储 长鑫存储 受益方` | 设备受益方 |
| C4 | `{日期} 半导体零部件 耗材 电子特气 光刻胶 靶材 受益方` | 材料/耗材受益方 |

日期区间建议：过去 30-60 天，确保覆盖扩产规划的发酵过程。

### 产业链受益方分类模板

| 环节 | 细分 | 受益逻辑 | 典型公司 |
|------|------|---------|---------|
| 设备 | 刻蚀/薄膜/光刻/清洗/CMP/量测/离子注入 | 存储扩产直接拉动设备采购，每万片月产能对应数十亿美元设备投资 | 北方华创、中微公司、拓荆科技、盛美上海、华海清科、中科飞测、至纯科技 |
| 零部件 | 石英件/陶瓷件/密封件/阀门/MFC/真空泵 | 设备交期拉长→零部件需求同步放大，国产替代加速 | 富创精密、康强电子、新莱应材、万业企业 |
| 硅片 | 300mm硅片/SOI硅片/外延片 | 存储扩产→硅片消耗量线性增长 | 沪硅产业、立昂微、有研硅、TCL中环 |
| 电子特气 | 六氟化钨/氦气/高纯气体 | CVD工艺刚需，存储层数增加→特气用量倍增 | 中船特气、华特气体、金宏气体、和远气体 |
| 靶材 | 钽/铜/钛/钨靶材 | 3D NAND层数增加→薄膜沉积次数增加→靶材消耗倍数增长 | 江丰电子、有研新材、阿石创 |
| CMP材料 | 抛光液/抛光垫 | 存储先进制程CMP步骤增加 | 安集科技、鼎龙股份 |

| 洁净室 | 洁净室工程/过滤 | 新建产线必须配套 | 柏诚股份、美埃科技、亚翔集成 |
