# 案例：上海杉达学院教务处 2026-2027 校历提取（2026-09-25）

- 入口：https://jwc.sandau.edu.cn/ → 「学校校历」栏目 /7048/list.htm → 各学年校历列表页。
- 校历正文页无文字，正文为两张 JPG（每学期一张），路径形如
  `/_upload/article/images/<hash>/<uuid>.jpg`，需带 Referer 下载。
- 瑞数 challenge 用 headless chrome `--virtual-time-budget=20000 --dump-dom` 一次通过。
- OCR 结果：第一学期 2026-09-14 ~ 2027-01-15（教学活动18周），
  寒假 2027-01-18 ~ 2027-02-28（6周含春节），第二学期 2027-03-01 开学。
- tesseract chi_sim 对表格校历的误识：竖线变 `|`/`l`，日期数字粘连（如 `261 7`），
  月份汉字识别尚可（"一月""二月"可靠）。周数行+月份行对照可推断逐日日期。
