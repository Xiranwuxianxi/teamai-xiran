## 使用方式

1. 用户发声音样本 → 预处理（去静音+标准化）
2. 用 MiMo voiceclone + 样本 + 这份文稿生成测试音频
3. faster-whisper 回听转写，核对数字/专名念对没有
4. 发给用户听，确认音色满意后再用于正式配音
