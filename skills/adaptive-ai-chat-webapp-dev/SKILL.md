# 自适应高级AI对话网页应用开发规范
## 技术栈标准
前端：React + TailwindCSS + 原生DOM渲染（避免使用版本兼容问题的第三方组件如新版react-markdown）
后端：FastAPI + WebSocket实时通信

## 开发规范
1. 配色要求：优先使用暖色系（如暖橙、粉橙渐变），禁止使用冷蓝紫系列的暗色渐变
2. WebSocket配置：必须使用动态获取当前域名的方式连接，禁止硬编码localhost
3. 组件规范：避免使用有已知版本兼容问题的第三方组件，优先用原生HTML标签实现基础功能
4. 动效要求：消息发送要有淡入动画，按钮、卡片要有悬浮反馈效果，提升高级质感

## 端口管理
1. 优先使用非通用端口（避免和用户面板、宝塔等服务常用端口8888、3000、80、443等冲突）
2. 启动服务前必须检查端口占用情况，kill进程时只能终止自身启动的服务进程，禁止误杀其他服务进程

## 交付前强制检查清单（必须全部通过才能交付）
1. 前后端所有依赖完整安装，无缺失报错
2. 本地测试：前后端服务正常启动，curl访问返回200状态码
3. 功能测试：页面无控制台错误，对话发送/接收功能正常，自适应布局在不同尺寸下正常显示
4. 网络测试：服务器防火墙/安全组对应端口开放，外网可以正常访问页面
5. 需求匹配：确认配色、功能、交互符合用户要求，无不符合预期的设计

## 常见问题排查流程
1. 页面只显示背景：优先检查第三方组件兼容问题，替换为原生实现
2. WebSocket连接失败：检查后端服务状态、WebSocket的host是否为动态获取
3. 外网访问失败：检查端口是否开放、服务是否监听0.0.0.0地址
4. 服务意外终止：检查是否有端口冲突、进程被误杀等情况
