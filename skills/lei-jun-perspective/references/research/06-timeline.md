# 雷军完整人生时间线

> 雷军（1969年12月16日—），湖北仙桃人，小米集团创始人、董事长兼CEO，中国著名企业家、天使投资人。

---

## 一、早年时期（1969—1991）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1969年12月16日** | 出生于湖北省仙桃市（原沔阳县） | 普通教师家庭，父亲是小学教师 |
| **1984年** | 考入仙桃中学（沔阳中学） | 湖北省重点中学 |
| **1987年** | 高考分数超清华北大线，但选择**武汉大学计算机系** | 据其自述，因好友在武大，且看重计算机专业 |
| **1989年** | **两年修完大学全部学分** | 仅用两年时间，完成大学四年课程 |
| **1990年** | 大学期间出版《**深入DOS编程**》 | 19岁编写，成为早期中文计算机编程畅销书 |
| **1991年** | 毕业于武汉大学计算机科学系 | 获学士学位 |
| **1991年7月** | 分配到**北京航天部某研究所** | 第一份工作，铁饭碗，但感觉"一眼望到头" |

### 早年关键转折点
- **1987年选择武大而非清北**：务实选择，奠定了技术底子
- **两年修满学分**：展现了极致的时间管理和学习效率，形成"快人一步"的思维模式
- **写书**：20岁前就通过知识输出建立影响力

## 二、金山时期（1992—2007）

| 时间 | 事件 | 备注 |
|------|------|------|
| **1992年1月** | **加入金山软件** | 第6号员工，放弃铁饭碗南下珠海 |
| **1992年8月** | 参与开发**盘古组件**（WPS Windows版） | 金山的重要产品转向 |
| **1995年** | 盘古组件遭遇市场失败 | 雷军第一次重大挫折，金山陷入生存危机 |
| **1996年** | **雷军曾提出辞职**，被求伯君挽留 | 迷茫期，休整半年，思考战略方向 |
| **1997年** | 金山推出**金山词霸**、**金山影霸**等工具软件 | 成功转型，找到生存之道 |
| **1998年** | 联想注资金山，雷军出任**金山软件CEO** | 29岁成为CEO，开启全面管理生涯 |
| **1998—2003年** | 领导金山与微软Office对抗 | WPS 97、WPS 2000 陆续发布，艰难守业 |
| **2000年** | 创办**卓越网**（B2C电商） | 雷军作为董事长，后于2004年以7500万美元卖给亚马逊 |
| **2003年** | 进军网络游戏 | 推出《剑侠情缘网络版》，成为重要收入来源 |
| **2004年** | 卓越网出售给亚马逊 | 获得天使投资的"第一桶金" |
| **2005年** | 金山软件启动上市筹备 | 多次尝试上市未果 |
| **2007年10月9日** | **金山软件在香港联交所上市**（代码：03888.HK） | 历时8年、5次冲击IPO终成功 |
| **2007年12月20日** | **辞去金山CEO职务**，保留副董事长席位 | 正式告别16年金山生涯，声称"休息一段时间" |

### 金山时期关键转折点
- **1995年盘古失败**：第一次重大商业失败，深刻反思"技术不是一切"
- **1996年辞职风波**：人生最低谷，在BBS上与网友交流，思考人生方向
- **2004年卖出卓越网**：获得财务自由，启动了天使投资之路
- **2007年离开金山**：38岁"退休"，进入人生第二阶段

## 三、天使投资时期（2007—2010）

| 时间 | 事件 | 备注 |
|------|------|------|
| **2007年底—2009年** | 转型**天使投资人** | 被称为"中国最成功的天使投资人"之一 |
| **2004年（前期）** | 投资**卓越网卖给亚马逊后的团队** | 早期项目 |
| **2005年** | 投资**拉卡拉** | 移动支付领域 |
| **2005年** | 投资**UC优视（UC浏览器）** | 100万美元，后UC被阿里收购，回报约1000倍 |
| **2006年** | 投资**凡客诚品**（VANCL） | 陈年创办，后成为知名电商品牌 |
| **2007年** | 投资**YY（欢聚时代）** | 李学凌创办，后于2012年纳斯达克上市 |
| **2008年** | 投资**乐淘网** | 鞋类电商 |
| **2009年** | 投资**好大夫在线** | 医疗健康领域 |
| **2010年前后** | 总结投资理念："**不熟不投**"、"只投人" | 投资关注团队而非商业模式 |

### 天使投资时期关键转折点
- **2008年产生"做手机"想法**：观察到移动互联网浪潮将至，功能机向智能机转换的历史机遇
- **反复思考创业方向**：在UC、YY等移动互联网投资中，深刻理解移动生态的爆发潜力
- **UC浏览器的成功**：让雷军看到移动互联网入口的巨大价值，坚定进入硬件+软件生态的信念

## 五、关键转折点与思想变化

### 转折点一：1995年盘古失败 → 学会商业思维
- 金山投入3年开发的盘古组件惨败，雷军首次意识到"**技术≠市场**"
- 开始学习市场、营销、管理，从"程序员雷军"转向"管理者雷军"

### 转折点二：1996年辞职风波 → 找到管理哲学
- 陷入人生低谷，差点离开金山
- 在CFIDO BBS上与人交流，读了很多书，形成了"**顺势而为**"的雏形思想
- 回来后带金山做词霸、影霸、游戏，实现了多元生存

### 转折点三：2004年卖出卓越网 → 获得财务自由与投资视野
- 第一次完整创业周期（0→1→卖），获得财务自由
- 开始天使投资，接触伟人（马化腾、丁磊等），视野彻底打开
- 领悟到"**风口**"的重要性

### 转折点四：2007年离开金山 → 开启第二人生
- 38岁退休，但实际是"退休式创业"的过渡期
- 总结金山16年经验与教训
- 确定了"**做一家伟大的公司**"的下一个目标

### 转折点五：2010年创立小米 → 事业巅峰
- 从零开始，用互联网思维做手机
- 提出"**专注、极致、口碑、快**"七字诀
- "**Are you OK？**"意外成为个人IP标志

### 转折点六：2015—2016年低谷 → 回归一线
- 销量暴跌，外界质疑"小米模式失效"
- 雷军亲自接管手机部，每天工作15小时
- 深刻反思：**"硬件+新零售+互联网"铁人三项**仍需补齐线下短板

### 转折点七：2021年宣布造车 → 人生最后一战
- "我愿意押上我全部的声誉"——最重的表态
- 从手机到汽车，从消费电子到新一代移动终端
- 2024年SU7成功发布，完成从"手机公司CEO"到"汽车公司CEO"的身份跨越

### 转折点八：2024—2026年 → 从成功到伟大
- 小米手机站稳高端 + 汽车业务突破
- "人车家全生态"战略成型，小米成为**中国极少数同时拥有手机+汽车+IOT完整生态的公司**
- 雷军作为中国新一代企业家的代表形象完全确立

## 六、雷军的核心思想与理念演变

| 时期 | 核心思想 | 代表作/表达 |
|------|---------|------------|
| 早期金山 | 技术至上、做民族软件 | "让中国软件走向世界" |
| 金山中后期 | 顺势而为、拥抱市场 | 盘古失败后转型 |
| 天使投资期 | 风口论 | "风口上，猪都能飞起来" |
| 小米早期 | 互联网思维七字诀 | "专注、极致、口碑、快" |
| 小米中期 | 铁人三项 | 硬件+新零售+互联网 |
| 2016年后 | 补课、厚积薄发 | 深耕供应链、线下渠道 |
| 2020年后 | 高端化+全球化 | 小米10起冲击高端市场 |
| 2023年后 | 人车家全生态 | 手机×汽车×AIoT |
| 2024—2026 | 技术立业、全生态 | "做时间的朋友，顺势而为" |
