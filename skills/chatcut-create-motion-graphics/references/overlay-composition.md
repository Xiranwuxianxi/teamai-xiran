# Adapt an overlay reference to the shot

Use the instance selected in [step 3](../SKILL.md#3-inspect-instances).
The search-result collage compares several instances; each selected instance
represents one design. Inspect that design's hero, not the whole search grid.
Read source context if its relationship with footage is unclear. Reference
photos can stand for current A-roll; their subjects and positions do not
determine the current shot's framing.

Carry useful hierarchy, alignment, spacing, proportions and reveal structure
into the actual content. A color swatch or an adjective alone is insufficient.
Use the confirmed project fonts, palette and materials, including when borrowing
a form from another style. An instance's typography/effect notes explain its
construction; membership in one pack does not make all examples visually identical.
Avoid adding generic panels, shadows or decoration absent from the chosen style.

Follow the background and transparency requirements in [step 4](../SKILL.md#4-author-and-create-the-mg).

For Chinese or longer copy, adjust widths and line breaks while preserving
hierarchy. Keep quotes accurate and replace example faces, logos, facts and
attributions with current content. Keep ordinary footage/backgrounds and MG
layers separate as described in the main skill. Use the inspected images while
writing JSX; an ID, URL or text description alone does not replace the visual input.

Review the complete timeline at entrance, the settled frame with most content,
and exit when relevant. Compare structure with the instance and appearance with
the fixed project style. Check subject/subtitle overlap, reading time, media crop,
spacing and legibility at viewing size. Adjust placement for composition problems
and the graphic for internal design problems. Report missing references or
unavailable visual checks rather than claiming they were inspected.
