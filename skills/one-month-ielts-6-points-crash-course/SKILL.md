# 雅思备考方案

## CET分数→雅思预估换算
| CET等级 | 分数区间 | 雅思预估 |
|---------|---------|---------|
| 四级425-450 | 刚过线 | 雅思4.5 |
| 四级450-500 / 六级425-450 | 中等 | 雅思5.0 |
| 六级450-500 | 中上 | 雅思5.0-5.5 |
| 六级500-550 | 较好 | 雅思5.5-6.0 |
| 六级550+ | 优秀 | 雅思6.0-6.5 |

**关键洞察**：CET侧重输入（阅读/听力），雅思卡分项永远是输出（写作/口语）。六级446的人裸考阅读听力可能5.5-6.0，但写作口语只有4.5，总分被拉到5.0。提分核心在输出端。

## 方案一：1个月极速版（目标6.0，单项5.5，每天2小时）
### 时间拆分
1. 前7天基础扫盲：每天1.5小时，仅背1600个雅思听力/阅读高频词+磨英音耳朵，无需学习语法/长难句/低频词
2. 中间18天单项突破：每天2小时，仅抓核心得分点，难题直接跳过，完全不做无用功
3. 最后5天模考冲刺：每隔1天做1套剑雅真题模考，熟悉考试节奏，无需刷新题

### 单项提分技巧（仅抓6分必须拿到的分）
1. 听力：只刷剑雅15-20的section1/section2，目标正确率14/40，难度更高的section3/4直接蒙C即可，总分可达5.5-6分
2. 阅读：仅练习填空/判断题（占总分60%），目标正确率80%，匹配题/heading题直接蒙，无需精读，找大写/数字/特殊符号定位即可快速拿分
3. 写作：背3个小作文高频题型模板（折线图/柱状图/表格，占考试概率80%）+10个大作文万能论点，无需写复杂句，没有严重语法错误即可拿到5.5-6分
4. 口语：准备10个通用万能素材，所有part1/part2话题均可套用，part3只要不停顿、能回应考官问题即可拿到5.5分

## 方案二：3个月稳扎版（保底6.0，冲6.5，每天2-4小时）
### 第1个月：输入端保底（阅读+听力冲6.0）
- 雅思阅读比六级简单——不用全读懂，找定位词就能得分
- 听力只练S1/S2，拼写+数字题全对就能拿5.5
- 每天背80个高频词，1个月搞定核心2400词
- 每天2-3小时

### 第2个月：输出端突破（写作+口语冲5.5）
- 写作：背模板不丢人，6分以下不需要原创，需要的是"不出错"
- 口语：10个万能素材覆盖所有话题，part2说到2分钟不停顿就是5.5
- 写作每天1篇大作文，用AI批改语法
- 口语每天15分钟录音回听纠错
- 每天3-4小时

### 第3个月：全真模考+查漏补缺
- 隔天1套剑雅全真模考（严格计时）
- 错题复盘：不是对答案，是搞清楚"错在哪一步"
- 口语每天20分钟，找语伴或AI陪练
- 考前一周只做：看错题本 + 保持手感

### Day1立即行动清单
1. 做一套剑雅阅读+听力摸底，知道真实起点
2. 下载"雅思哥"App——口语题库+写作范文全免费
3. 当晚背50个听力高频词，有动作焦虑就消一半

## 保底方案
若雅思差0.5分可配4周语言班，或转考多邻国英语测试（比雅思简单30%，在家即可考，2天出分，90%的英国院校均认可）

## 焦虑缓解策略
焦虑本质=目标模糊+路径不清，解决方案：
1. 时间可视化：倒计时App设考试日期，每天看到倒计时反而踏实
2. 摸底定锚：第一天做真题摸底，知道起点后焦虑自动降50%
3. 周计划驱动：把月计划拆成周计划，每周日晚10分钟对进度，有节奏感就不慌
