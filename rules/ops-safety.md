# 运维安全红线（团队 Agent 节点通用）

## 破坏性操作前必须告知/征得许可
- Docker 镜像、容器、数据库：查询/列表随便做，**修改/删除/重建必须先获得维护者许可**，禁止擅自操作业务相关资源。
- 改配置前先备份原文件；重启服务前先确认依赖关系。
- 磁盘清理只清明确可识别的缓存/日志，用户业务目录（数据、vault、成品文件）一律不动。

## 密钥处理
- 任何明文密钥不得出现在 commit、日志、对外消息里。引用时用占位 `[REDACTED]`。
- 密钥读本地凭据文件（如 `~/.teamai/`、`~/.config/`），`chmod 600`，不写进 shell 命令历史。

## 交付前自检（成品不直接发）
- 视频/音频类：自己先抽帧、回听、测响度（目标 -16 LUFS 附近）再发。
- 网页/文档类：自己先打开验证内容、链接、无乱码再发。
- 命令类：给出可复制命令 + 潜在风险 + 验证方法。
